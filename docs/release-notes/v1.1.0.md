这是「微信文章采集器 · MN4」的第一个小版本更新，重点补全离线文章的保存位置设置。

## 新增功能

- 离线 HTML 可选择“每次手动选择位置”。
- 可直接使用 Chrome / Edge 的默认下载位置。
- 可保存到下载目录下的指定子文件夹，例如 `MarginNote/微信文章`。
- 设置默认位置后，仍可使用“HTML 另存为…”为单篇文章临时选择其他位置。
- 保存设置仅存储在本机扩展数据中，不会上传。

## 安全与兼容

- 子文件夹仅接受下载目录内的相对路径。
- 绝对路径、`..` 路径穿越和非法文件名字符会被拒绝或清理。
- 默认仍为“每次手动选择位置”，升级后不会突然改变原有下载行为。

## 关于 PDF 保存位置

普通 Chrome / Edge 扩展无法替用户控制系统“打印为 PDF”的绝对保存路径。因此 PDF 仍需在打印对话框中手动选择位置；本次默认位置设置适用于离线 HTML。

下载下方 ZIP 并解压，然后在扩展程序页面重新加载该文件夹即可升级。
