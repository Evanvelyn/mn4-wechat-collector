# 微信文章采集器 · MN4

面向 MarginNote 4 阅读工作流的本地优先 Chrome / Edge 扩展：搜索微信公众号文章、按相关性与来源质量排序、批量打开，并在图片完整加载后另存为可搜索 PDF。

> 当前稳定版本：`v1.1.0`

## 为什么做这个项目

我使用 MarginNote 4 阅读和整理资料时，希望把微信公众号里来自大公司技术团队、研究团队和高质量行业媒体的文章纳入自己的阅读库。

原来的流程有两个明显问题：

1. **发现困难**：知道自己想读“Agent 评测”之类的主题，但不知道哪些公众号写过、哪些来源更值得优先阅读。
2. **图片容易缺失**：直接把公众号网页链接交给 MarginNote 4 保存时，部分文章会因为微信图片懒加载、CDN 地址或网页抓取方式而丢失正文图片。

因此我做了这个扩展，把流程收拢为：

```text
输入关键词
  → 搜索公众号文章
  → 按内容相关性、可信来源和时效性排序
  → 勾选并打开文章
  → 强制加载正文图片
  → 浏览器另存为可搜索 PDF
  → 导入 MarginNote 4
```

它不是微信公众号爬虫平台，也不会尝试绕过验证码、登录或付费限制。它只处理普通用户可以访问的公开页面，并把最后的选择权留给用户。

## 功能

- 通过搜狗微信搜索按关键词发现公众号文章。
- 展示标题、摘要、公众号名称和发布日期。
- 根据关键词相关性、大厂技术账号白名单和发布时间生成透明质量分。
- 支持勾选多篇结果并在后台打开。
- 在公众号文章页强制加载懒加载图片，再调用浏览器打印。
- 通过“另存为 PDF”生成文字可搜索、图片完整的阅读文档。
- 额外支持离线 HTML 归档：正文图片转换为内嵌 `data:` 数据，不再依赖微信图片链接。
- 搜索触发验证码或不可用时，明确显示错误并提供手动搜索入口。
- 全程本地处理文章，不上传正文，不读取或保存微信 Cookie。
- 可设置离线 HTML 的默认保存方式：每次询问、浏览器默认目录或下载目录下的指定子文件夹。
- 设置默认位置后，仍可通过“HTML 另存为…”临时手动选择其他位置。

## 安装

### 从 Release 安装

1. 在 GitHub Releases 下载 `mn4-wechat-collector-v1.1.0.zip`。
2. 解压 ZIP。
3. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
6. 在浏览器扩展菜单中固定“微信文章采集器 · MN4”。

### 从源码安装

```bash
git clone https://github.com/Evanvelyn/mn4-wechat-collector.git
cd mn4-wechat-collector
```

然后在浏览器扩展管理页选择项目根目录。扩展没有运行时依赖，不需要构建，也不需要执行 `npm install`。

## 使用方法

### 1. 搜索与挑选文章

1. 点击扩展图标。
2. 输入关键词，例如 `Agent 评测`。
3. 查看来源、日期、摘要、质量分和推荐原因。
4. 勾选需要的文章，点击“打开已选”。

### 2. 生成 PDF

1. 打开一篇 `mp.weixin.qq.com` 公众号文章。
2. 点击扩展图标。
3. 点击“打印为 PDF”。
4. 扩展会先加载正文中的懒加载图片，然后打开浏览器打印对话框。
5. 在目标打印机中选择“另存为 PDF”。

浏览器扩展无法替用户设置打印为 PDF 的绝对路径，因此 PDF 位置仍需在打印对话框中选择。

### 3. 设置离线 HTML 保存位置

在扩展的“离线 HTML 保存位置”中可以选择：

- **每次手动选择位置**：保存时弹出系统窗口。
- **使用浏览器默认下载位置**：不再询问，直接使用 Chrome / Edge 的下载设置。
- **保存到下载目录的子文件夹**：例如填写 `MarginNote/微信文章`，文件会进入浏览器下载目录下的对应文件夹。

即使已经设置默认位置，也可以点击“HTML 另存为…”临时选择其他位置。出于浏览器安全限制，子文件夹必须是下载目录内的相对路径，不能填写 `/Users/...` 等绝对路径。

### 4. 导入 MarginNote 4

在 Finder 中找到 PDF，右键选择：

```text
打开方式 → MarginNote 4
```

也可以先在 MarginNote 4 中进入目标文件夹或学习集，再导入生成的 PDF。

“保存离线 HTML”主要用于长期归档和核对原始图文；导入 MarginNote 4 时推荐使用 PDF。

## “高质量”是如何判断的

当前版本采用可解释的综合评分：

- 内容相关性：标题和摘要命中关键词的程度。
- 来源权威性：美团、字节、腾讯、阿里、百度、华为、京东、小米、网易、快手等技术或研究账号获得来源加分。
- 时效性：近期发布文章获得适度加分。

公开搜索无法稳定获得其他公众号真实的阅读、点赞和在看数据，因此本扩展**不会伪造或猜测互动量**。来源白名单也只是一种排序信号，不代表对文章内容的背书。

## 为什么图片不会像网页导入那样轻易丢失

公众号正文图片经常使用 `data-src` 懒加载属性。普通网页抓取器可能只拿到占位符，没有触发真实图片加载。

本扩展在打印前会：

1. 找到公众号正文区域；
2. 把 `data-src` / `data-original` 转换成实际图片地址；
3. 将图片切换为 eager loading；
4. 等待图片解码或超时；
5. 再打开浏览器打印对话框。

离线 HTML 模式会进一步下载微信图片并转换为 Base64 内嵌数据。若个别图片确实无法下载，文档会明确标记失败位置，而不是留下一个看似正常、之后却会失效的链接。

## 隐私与安全

- 不读取、导出或保存微信 Cookie。
- 不把文章正文上传到第三方服务。
- 不包含统计 SDK、广告或远程执行代码。
- 搜索请求只发送到搜狗微信搜索。
- 图片请求仅允许微信图片域名。
- 不绕过验证码、登录墙或付费内容。
- 不直接修改 MarginNote 数据库或 `MNDocs` 内部结构。
- 对外部搜索链接、文章 HTML 和文件名进行协议限制与清理。

## 已知限制

- 搜狗微信存在频率限制，频繁请求可能出现验证码。
- 搜索覆盖范围和排序受搜狗微信索引影响。
- 搜狗中转链接可能过期，建议搜索后及时打开。
- 付费、已删除、登录后才能访问的文章不受支持。
- 视频、音频和小程序卡片不会被转换成可播放的 PDF 内容。
- 单篇文章最多处理 200 张图片；单张图片上限 20 MB，图片总量上限 150 MB。
- 扩展不能控制系统打印对话框中的 PDF 保存路径。
- v1.1.0 不直接选择或修改 MarginNote 内部文件夹；当前通过 PDF 导入完成衔接。

## 技术结构

```text
manifest.json
src/
├── background/        搜狗微信跨域搜索请求
├── lib/               搜索解析、评分、离线文档生成
└── popup/             搜索、选择、导出界面
tests/                 固定页面样本和单元测试
scripts/               静态验证与 Release 打包
docs/decisions/        关键架构决策记录
```

项目使用 Manifest V3 和原生 JavaScript，不依赖前端框架或远程后端。
